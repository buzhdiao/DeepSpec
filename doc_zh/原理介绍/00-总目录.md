# DeepSpec 原理介绍·总目录

## 阅读导引

本文档是 DeepSpec 仓库的原理性介绍，面向三类读者：希望理解投机解码草稿模型如何被训练与评测的研究者、需要在自有环境复现或部署这套系统的工程师、以及准备向仓库贡献新算法的开发者。全书共十三章加本目录，按"原理—数据—模型—损失—系统—评测—超参—实战"的顺序组织：前两章建立投机解码的数学基础与三种草稿算法的设计空间；第三、四章讲清训练数据从哪里来、监督信号如何以数十 TB 的二进制缓存形态存在；第五、六章深入草稿模型的结构与损失；第七至九章覆盖训练框架、检查点与分布式调度；第十、十一章是评测体系与超参数的逐项解读；第十二、十三章是复现指南与实战诊断。每一章都遵循同一种写法：先讲"为什么"（动机与约束），再讲原理与权衡（推导、流程、内存布局），最后落到代码（真实文件路径与函数名）。文中引用的每一个文件与函数都存在于当前仓库；读者遇到任何概念的细节疑问，都可以沿"章-源码对照地图"（本目录末节）找到第一现场。

阅读路径建议按角色选择：研究者走第一、二、五、六、十、十一章；工程师走第三、四、七、八、九章与第十二章；贡献者再补第十二章的接口清单与第十三章的回归集。任何角色都建议先读完第一章——它是全书的记号与直觉底座。各章之间的大量交叉引用构成了一个闭环网络：从任一章出发，沿引用至多三跳可达任何被引用的原理。

## 各章摘要

第一章（投机解码原理与接受率数学）：从"解码是访存受限"出发建立加速的动机，完整推导拒绝采样加残差修正的无偏性；证明接受率等于一减去半幅全变差距离，给出期望接受链长与每轮期望产出的连乘公式，并推演加速比的时间账与最优提案长度的经济学。本章的记号（目标分布 p、草稿分布 q、逐位接受率、期望产出、提案长度）贯穿全书。对应代码：deepspec/utils/sampling.py 与 deepspec/eval/base_evaluator.py 的验证函数。

第二章（三种草稿算法）：在"自回归递归对块状并行"的设计谱系上定位三种算法——Eagle3 以单层主干加五层目标特征加训练时七步展开（TTT）换取极小起草开销；DFlash 把起草完全并行化并以纯净交叉熵作消融基线；DSpark 在块状骨架上叠加马尔可夫低秩偏置（半自回归）与置信度头（长度调度）。锚点无放回采样与块稀疏掩码的三条可见性规则、马尔可夫头的训练并行与推理逐步双路径，是本章的结构核心。对应代码：deepspec/modeling/ 两个算法目录与 config/ 的十二个配置。

第三章（数据流水线）：论证"草稿要模仿目标模型的部署分布"这一数据第一性问题，覆盖下载切分（留出用户轮次）、推理引擎重生成答案（采样参数即部署配方、断点续跑与错误分流）、对话模板注册表与损失掩码（只监督助手段）、内存映射的多文件数据集与行索引缓存。对应代码：scripts/data/ 与 deepspec/data/parser.py、jsonl_dataset.py。

第四章（目标缓存）：推导"计算一次、存储复用"的显存与算力账；解剖存储协议——五十六字节定长索引（格式串八字段）、五段字节布局（词元、双掩码、多中间层隐状态、末层隐状态）、版本号与清单；写入端的异步队列背压与多卡合并的原子改名，读取端的内存映射、最近使用缓存与三层校验。对应代码：deepspec/data/target_cache_dataset.py 与 scripts/data/prepare_target_cache.py。

第五章（模型实现）：派生式配置（深拷贝目标配置）、双流数据流（目标上下文跨注意与草稿自身流）、Gemma 家族的四处结构差异（缩放嵌入、键值归一化、键值等价变体、软上限与四归一化）、两份键值缓存的生命周期纪律与位置连续性、参数的继承冻结清单、两种注意力实现的训练评测分野。对应代码：deepspec/modeling/ 的配置构造与建模文件。

第六章（损失设计）：以"接受率的可微代理"统摄全部损失——DSpark 的一阶蒸馏主项加交叉熵辅项加置信度二元交叉熵、全局分母的多卡一致性推导、逐位指数衰减对误差复利的定价、Eagle3 的按步衰减与 Triton 融合核的在线两遍法（行级标量跨自动求和、梯度原地写回的省显存契约）。对应代码：deepspec/modeling/ 两个损失文件与 deepspec/utils/metrics.py。

第七章（训练框架）：训练器的职责边界与算法签名（构建与损失两个入口）、FSDP 分片策略谱系与二维设备网格、bfloat 计算加单精度主参数的混合精度推导、梯度累积的不同步窗口、两段式调度器的可序列化设计、无状态可续训采样器（种子派生洗牌、单整数进度）、微步时钟与主循环骨架。对应代码：deepspec/trainer/base_trainer.py 与 deepspec/utils/optim.py、distributed.py。

第八章（Checkpoint 体系）：四类内容（权重、逐卡训练状态、配置快照、原子指针）、四阶段保存协议与屏障节奏、四路随机数状态、单一真值的微步计数、最新符号链接的原子更新、恢复期的拓扑强校验与逐位等价性论证、崩溃矩阵与演练清单。对应代码：deepspec/trainer/ckpt_manager.py。

第九章（分布式与调度）：双流预取器（后台取数、侧流搬运、主流计算的三级流水线）、锁页内存与窄类型上转的带宽纪律、挂起控制器（监测线程、屏障加广播的信号转意志、保存即让位）、多节点坐标换算与环境变量矩阵、数据并行梯度等价性的完整推导。对应代码：deepspec/data/cuda_prefetcher.py 与 deepspec/utils/hfai_suspend.py。

第十章（评测体系）：评测器路由（模型自描述）、九项任务与单轮协议、五步解码循环（预填充、提案、验证、提交、裁剪）、验证函数的并行判定与奖励词元、DSpark 的块前向提案与置信度截断、校准三量（期望校准误差、曲线下面积、布里尔分数）与可靠性图、多卡归并的计数口径。对应代码：deepspec/eval/ 目录与 eval.py。

第十一章（超参数体系）：十二个配置文件的逐项解读——实验标识与种子、块长与展开步数的经济学、层取点的等距论证、锚点数与监督密度、两个头的开关即消融链、损失权重与衰减形状、训练与数据段全部字段，附变动范围、维度对照、响应表与逐行走读。对应代码：config/ 目录与 deepspec/utils/constant/public.py。

第十二章（复现指南与总结展望）：从环境到评测的完整路径与分天时间表、三页硬件账本、失败清单与求助路径、复现质量三级（流程、数字、口径）、面向新目标模型与新算法的适配清单、全书要点十条与三条展望（树形提案、在线自适应、缓存演进）。对应代码：README.zh-CN.md 与 scripts/ 的启动脚本。

第十三章（调优诊断实战）：按症状归因的诊断树（加速比、收敛、精度、校准）、逐位衰减曲线的形态学、分层吞吐排查、健全性检查单、调优工作流与回归集、部署交接清单、三个典型场景剧本与五段式诊断报告模板。对应代码：以全书各章为原理出处。

## 术语表

投机解码：用廉价草稿模型连猜词元、由目标模型并行验证并按拒绝采样修正的解码框架，输出分布与目标模型单独解码严格一致。草稿模型（draft model）：被训练来模仿目标模型逐词元分布的轻量模型，DeepSpec 的训练对象。目标模型（target model）：被加速的大模型，同时是草稿的监督信号来源与验证裁判。拒绝采样：以概率取两分布概率之比的上限接受草稿词元、拒绝处从归一化残差分布重采的机制。接受率：草稿词元被验证接受的概率，等于两分布的重叠质量，也等于一减半幅全变差距离。全变差距离：两分布逐词元绝对差之和的一半，草稿质量的核心度量。期望产出：一轮验证平均产出的词元数，等于一加逐位接受率前缀连乘和。提案长度：单轮起草的词元数，对应配置中的块长或展开步数（默认七）。TTT（训练时展开）：Eagle3 的训练范式，训练时把推理期的自回归展开搬进计算图逐蒸馏。锚点：块状并行训练中被采样的监督起点，其后的块内位置并行预测。半自回归：DSpark 的起草形态——并行基础分布加逐步施加的低秩马尔可夫偏置。马尔可夫头：把前驱词元经低秩分解映射为逐词元对数几率偏置的修正头。置信度头：预测逐位置"前缀仍被接受"概率的线性头，推理期用于提案长度调度。目标缓存：离线物化的目标模型隐状态监督信号，五段二进制分片加定长索引的存储协议。分片：缓存的数据卷，写满即封、只读 thereafter。清单：缓存的全局元数据文件，含版本与分片对账信息。微步：训练时钟的基本单位，消费一个微批。累积窗口：多次微步共享一次归约与更新的梯度累积区间，保存与恢复的天然边界。主参数：优化器持有的单精度参数副本，低位宽模型权重的数值完整性的保证。无状态采样器：洗牌顺序由种子加轮次派生、进度压缩为样本偏移的分布式采样器。最新符号链接：指向最近检查点的原子维护指针，训练恢复与评测加载的默认入口。挂起：调度平台要求让出机器的信号，训练以其检查点保存后优雅让位。置信前缀：按置信度截断的提案长度，阈值取零退化为整块提案。校准：预测概率与真实事件频率的一致程度，由期望校准误差等三量度量。

## 全书的三条主线

把十四章的内容压到最紧，全书其实在讲三条互相咬合的主线，读懂它们再回头看任何一章都会有"原来在这条线上"的定位感。

第一条主线是概率论的主线：一切从"分布等价"开始。投机解码之所以是投机解码而不只是"小模型帮大模型"，在于拒绝采样把正确性变成了一条可以证明的定理——无论草稿多差，只要验证与修正严格按第一章的公式执行，输出分布与目标模型逐词元采样完全一致。这条定理给整个系统划定了游戏规则：草稿的一切自由度都只影响效率，不影响正确性；反过来，效率的上界也由定理给出——接受率等于一减半幅全变差距离，期望产出按前缀连乘公式计算，加速比是产出与成本之比。全书此后的每一个设计决定，几乎都能在这三个量上找到自己的位置：算法抬高接受率（第二章的两种起草哲学）、损失逼近全变差（第六章的蒸馏主项）、评测测量产出（第十章的分布统计）、超参为以上一切定价（第十一章）。概率主线给读者的最重要的思维工具是"任何优化主张必须回答它优化的是哪个量、以什么为代价"。

第二条主线是数据的主线：监督信号决定草稿的天花板。草稿是被训练来猜目标模型的，而"目标模型会怎么输出"这件事在训练开始前就必须被完整地、正确地记录下来——第三章的答案重生成保证记录的来源对齐（目标模型自己的输出、自己的采样参数、自己的运行形态），第四章的目标缓存保证记录的形态可复用（一次成型、三十八 TB、字节级可校验、随机可寻址）。数据主线的关键洞察是"对齐错误是不可训练回来的"：结构再好、损失再精，若草稿拟合的分布不是目标模型的部署分布，接受率就有一个先天缺口。这条主线也解释了仓库里最"重"的资产为什么是缓存而不是模型——缓存是数据主线的物化形态，三种算法共享同一份缓存的事实，正是算法比较得以公平的物理基础。

第三条主线是工程的主线：让长时间的、分布式的、会被打断的计算保持可复现。第七章的微步时钟把训练的全部节奏统一到一个整数上，第八章的四阶段检查点与四路随机数把"中断"从灾难降级为事件，第九章的双流预取与挂起控制器分别对付性能气泡与平台信号，第四章的原子改名与第八章的原子指针是同一个可靠性元模式在不同层的复用。工程主线的独特价值在于它的可迁移性：原子改名、逐方对账、确定性派生、单一真值、显式失败——这五个模式没有一个依赖具体的算法或框架，任何长期训练系统的设计者都可以直接搬走。三条主线的咬合关系也值得说一句：概率主线定义"对"，数据主线提供"料"，工程主线保证"稳"——缺任何一条，剩下的两条都无法独立成立，这正是"全栈"一词在这个仓库里的真实含义。

## 交叉阅读的几个入口

除按角色选定的线性路径外，几个主题式的交叉阅读入口值得单列，它们把分散在不同章的同类内容聚成一束。入口一，"接受率"主题：第一章给出定义与公式，第二章给出抬高它的结构手段，第六章给出训练它的可微代理，第十章给出测量它的口径，第十三章给出它不达标时的诊断树——五个章节构成这个核心量从理论到实战的完整生命周期。入口二，"缓存与存储"主题：第三章的数据来源、第四章的字节协议、第七章的读取吞吐、第八章的检查点存储、第十二章的容量规划——凡是"大量字节躺在磁盘上如何被正确且高效地使用"的问题都在这一束里。入口三，"可靠性与原子性"主题：第四章的清单落盘与多卡合并、第八章的保存协议与指针更新、第九章的信号广播与让位时序——原子改名作为元模式出现三次，每次的上下文不同而手法相同。入口四，"口径纪律"主题：第三章的生成参数对齐、第六章的分母口径、第十章的评测口径、第十一章的审查清单——"两个数字要可比必须先同口径"这条朴素原则，在每个环节都有具体形态。建议读者在通读一遍之后，按这四个入口再各走一遍：主题式重读暴露的是线性阅读难以察觉的结构呼应，而这些呼应恰恰是设计（而非巧合）的证据。
